# Instagram Integration

Use current official Meta/Instagram APIs and supported professional-account capabilities. Confirm account type, app mode, permissions, review requirements, connected Facebook Page requirements and endpoint availability before designing a workflow.

Never assume a personal account can use professional messaging/publishing endpoints. Do not scrape, collect passwords, automate fake engagement, evade limits or use unofficial private APIs.

Use OAuth, minimum scopes, secure token storage, webhook verification and rate-limit handling. Obtain explicit approval before publishing, messaging, deleting or changing account settings. Verify publication/message status from the API response.
