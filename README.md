A practical, security-first skill collection for Android engineering, custom ROMs, device operations, software development, design, GitHub, Google services, browsers, messaging and social platforms.

## Skill layout

All skills use the Agent Skills format: a directory containing a `SKILL.md` with YAML frontmatter (`name`, `description`) and task-specific instructions.

## Workflow

The collection includes a Superpowers-derived workflow discipline (from [obra/superpowers](https://github.com/obra/superpowers)): brainstorm first, write a short plan, implement in small verifiable slices with tests, verify before claiming completion, and review after each task. The two dedicated skills are `superpowers-subagent-driven-development` and `superpowers-dispatching-parallel-agents`; the same discipline is woven into `brainstorming`, `planning-and-task-breakdown`, `incremental-implementation`, `test-driven-development`, `debugging-and-error-recovery`, `verify-live-state`, `code-review-and-quality`, `git-workflow-and-versioning`, `skill-creator` and `using-agent-skills`.
